# SmartMind AI Assistant

A modular Python chatbot framework featuring custom memory recall, mathematical expression evaluation, and real-time telemetry logging.

## Core Features
- **Modular Architecture:** Clean structural separation across core logic, memory handlers, knowledge lookup, and system utilities.
- **Memory Recall:** Tracks context and persists user profile attributes across sessions.
- **Math Engine:** Parses and evaluates mathematical expressions safely.
- **Telemetry & Interface:** Includes terminal UI loading components, system banners, and logging.

## Project Structure
- `Main.py` — Primary bootstrapper and execution loop
- `chatbot.py` — Core conversational router and response engine
- `memory.py` — Context persistence and memory storage
- `knowledge.py` — Structured knowledge retrieval module
- `utils.py` — Mathematical evaluation helpers and loading interface
